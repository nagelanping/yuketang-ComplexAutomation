# yuketang-ComplexAutomation

雨课堂复合自动化 userscript。项目在 `ref/` 下已有刷课、字体反混淆与多模态 AI 答题脚本的基础上重构，以课程目录页为入口自动遍历并处理视频、音频、课件、批量章节、作业与讨论。

## 工作方式

脚本以服务器端记录的学习进度为准驱动遍历：

- 每轮扫描课程目录，按顺序定位第一个未完成的学习项并处理；
- 处理完整页重载、自动续跑，重新扫描；已完成的项自然跳过，推进到下一个未完成项；
- 中途清缓存、刷新、换设备都不影响：重新进入目录页即可接着刷。

进度不依赖本地游标，因此不会因为本地记错位置而漏掉中间未完成的小节。同一项反复推不动 满3次 即跳过并告警，避免在已过截止、模型答不全等情况下死循环。

## 功能

- 视频、音频自动播放：设置倍速、静音、接管暂停后自动恢复，起播时把播放位置重置到开头（避免中间段漏刷），播放完成返回目录。
- 批量章节自动展开，逐个处理内部视频、音频、图文、作业与讨论。
- 讨论区（`taolun` / `forum`）读取教师正文，用文本请求让模型生成回复，填入回复框发表；关闭 AI 自动作答时改为跳过。
- PPT / 课件自动翻页与播放。
- 作业用浏览器内截图截取题面，通过 OpenAI 兼容接口调用多模态模型作答，支持选择题、多选题、判断题、填空题。
- 接口支持 Chat Completions 与 Responses 两种格式，自动补全端点；鉴权支持 Bearer、`x-api-key`、`api-key`，可自动识别。
- 支持 thinking / CoT、流式传输与自定义 max tokens。
- 字体反混淆常开（截图答题依赖）：题目文本被混淆字体做了字形置换，脚本还原后截图与复制才是真实文字。

## 文件

- `yuketang-ComplexAutomation.user.js`：主 userscript，单文件交付。
- `AGENTS.md`：面向 LLM Agent 的架构说明，开发者也可参考。
- `scripts/`：开发期检查脚本（10 个 `*-selftest.cjs`、`prompt-sync-check.cjs`）与 `ykt-inspect/`（BiDi 调试用小工具）。改动代码后按 `AGENTS.md` 的「必查项」跑。
- `tmp/`：本地诊断素材（页面抓取、站点 bundle、字体素材与截图、一次性探针），不入库。结构见 `AGENTS.md` 的「仓库结构」。
- `ref/`：参考脚本来源，保留用于审计和对照。

## 安装 & 使用

1. 安装 Tampermonkey 等 userscript 管理器。
2. 打开 `yuketang-ComplexAutomation.user.js` 并安装脚本。
3. 进入雨课堂课程目录页，点击脚本面板中的 `模型设置`。
4. 填入 API URL、API Key、模型名称，按需调整接口格式、鉴权方式、最大 Token，以及 thinking、流式传输、自动作答。
5. 点击 `开始`。

面板按钮：

- `模型设置`：AI 接口配置与功能开关。保存后写入 `localStorage`。
- `清除失败记录`：清空本次会话计数与续跑标记。仅在某些项被安全阀跳过、想重新尝试时使用。
- `暂停` / `继续`：暂停或恢复当前循环。**不会取消已经在途的 AI 请求**，请求返回后流程仍会继续往下走（选答案、点提交）。要彻底停住用 `终止`。
- `终止`：立刻取消在途的 AI 请求、清掉续跑标记，各循环入口随即退出，且不再接受 `开始`。恢复方式只有刷新页面。
- `开始`：启动遍历。目录页交棒给新标签期间按钮仍显示「运行中」，此时可再次点击以手动恢复。

## 纯刷视频模式

不开启 AI 自动作答时，脚本进入纯刷视频模式：作业与讨论项被直接跳过，只刷视频、音频、课件。需要自动答题与讨论区回复时，在 `模型设置` 里开启。

## AI 接口配置

API URL 可以填完整端点，也可以只填域名或基础路径，脚本按配置补全：

- Chat Completions：`/v1/chat/completions`
- Responses：`/v1/responses`
- 兼容 `/chat/completion`、`/chat/completions`、`/response`、`/responses`，以及只写到 `/chat` 的地址
- 阿里云 `dashscope.aliyuncs.com` 域名补 `/compatible-mode/v1`

默认行为：

- thinking / CoT：开启。
- stream：开启，60 秒无响应判定超时。
- max tokens：留空自动选择，thinking 开启时 `32768`，关闭时 `4096`。
- 不发送 `temperature` 与 `top_p`，由服务商默认值决定。

## 使用补充

- 在课程目录页启动。V2 内容页（`/v2/web/*` 且没有 `.logs-list`）会拒绝启动；`ai-workspace/lms-graph/*` 页面可以直接启动，脚本会按该页左侧的知识点列表依次处理。
- 首次使用先只开视频 / PPT 流程，确认目录能正常返回与续跑后，再开启 AI 自动作答。
- 作业答题依赖截图识别：窗口尺寸变化、题面被遮挡、页面未加载完、模型不支持图片都会导致失败。
- 讨论要求提交附件这类模型做不到的事时，会返回拒答标记 `{refuse}`；脚本不发表回复，把该条目标记为需人工处理。
- 日志出现 `XXX 连续 3 轮未推进，跳过`，多为该项已过截止或模型答不全；确认无误后可点 `清除失败记录` 重试。
